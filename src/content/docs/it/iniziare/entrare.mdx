## Indirizzo e porta
<Command syntax="play.litness.gg" description="Indirizzo per Java e Bedrock. È un indirizzo server, non un comando da digitare in chat." source="LIT-PLAY" />
Per Bedrock, la porta è **19132**. Entrare su Litness non ha un costo; il gioco e l’account restano necessari. <SourceRef id="LIT-PLAY" />

## Minecraft Java
1. Avvia Java Edition e apri **Multigiocatore**.
2. Aggiungi un server chiamato Litness con indirizzo `play.litness.gg`.
3. Salva e selezionalo dall’elenco per connetterti.

## Minecraft Bedrock
Nella schermata **Gioca → Server**, aggiungi Litness con l’indirizzo indicato e porta `19132`, quindi salva e connettiti. La disponibilità dell’aggiunta manuale può dipendere dalla piattaforma: la wiki non documenta metodi alternativi per console.

## Se la connessione fallisce
Ricontrolla indirizzo e porta. Le versioni Minecraft supportate non sono precisate in questa guida: consulta la pagina ufficiale e chiedi supporto sul Discord prima di cambiare client o installare componenti.
